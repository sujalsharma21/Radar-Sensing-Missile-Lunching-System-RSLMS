# 🔧 Circuit Design

<p align="center">
  <img src="RESULTS/circuit.jpeg" width="900">
</p>

The complete electronic architecture consists of:

- ESP32 DevKit V1
- HC-SR04 Ultrasonic Sensor
- 3 Servo Motors
- LM2596 Step-Down Converter
- Buzzer
- Status LEDs
- Launcher Mechanism
- Battery Power Supply
- Voltage Divider Protection Circuit
